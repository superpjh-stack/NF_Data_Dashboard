# 니즈푸드 데이터 대시보드

2026-10-22 사용자 승인: 고려솔더의 통합 현황·데이터 탐색·분석 구성을 니즈푸드 원본에 적용.

로컬 전용 Python HTTP 서버 + SQLite + 의존성 없는 HTML/CSS/JS. 원본 파일은 수정하지 않는다. Excel/XLSB 읽기에 openpyxl/pyxlsb 사용. 외부 API, 폰트, CDN, 클라우드 업로드 없음.

통합 현황, 원본 탐색, 레시피/배합, 생산/수불, 품질, 센서/RAG 연결 상태를 제공한다. 파일 수와 추출 행 수는 합산하지 않는다. SHA256 동일 사본은 대표 파일만 구조화하고 사본은 원본 목록에서 보존한다. 잠금 임시파일과 복사해서 사용하는 빈 양식은 집계 대상을 분리한다. 복구본은 자동 제외하지 않고 검토 대상으로 표시한다.

생산과 수불 대사는 실제 셀 날짜가 있는 공통 날짜만 사용한다. 원재료명은 NFC + 공백 정리만 적용하며 괄호/원산지/브랜드를 임의 병합하지 않는다. 사용량의 kg 단위가 확인된 행만 합산한다. 수불은 하루 품목별 사용량을, 생산은 하루 모든 끼니의 투입량을 합해 비교한다. 수불과 생산의 수치 차이는 장부 검토 후보이며 불량 판정이 아니다.

레시피 안정성은 생산일지에서 같은 날짜·끼니·메뉴의 원재료 집합을 하나의 실행으로 보고 최빈 구성 비중을 계산한다. 승인 레시피 또는 조리 품질 판정으로 표현하지 않는다. 1인량 분포는 동일 메뉴·원재료별 g 단위 집단으로 제한한다. 조리계획서는 계획, 생산일지는 기록으로 별도 집계한다.

SQLite에 파일 해시, 추출 상태, 정형 행과 원본 셀 위치를 보존한다. 재처리는 새 임시 DB 완성 후 원자 교체. 실패한 파일은 상태와 오류를 남긴다. 원본 다운로드는 등록된 파일 ID로만 접근하며 원본 루트 밖으로 나가지 않는다. 서버는 127.0.0.1로 바인드한다.

검증: 통계 경계값, 양식별 파서, 임시/중복 제외, 장부 대사 단위/공통기간, 실제 원본 셀 대조, API 및 브라우저 상호작용과 반응형 화면.

## 2026-10-22 EDA·ML 검토 및 파란색 테마 확장

사용자 요청에 따라 파란색 테마로 변경하고 기존 앱 안에 EDA·ML 검토 화면을 추가한다. `src/eda.py`가 읽기 전용 SQLite 스냅샷에서 데이터별 수치 보유율·분포·기간 누락·반복 메뉴 구성·동일 메뉴/원재료 IQR·장부 연결·수식 정합성을 산출한다. 실제 날짜가 없는 계획서를 파일명으로 연결하지 않는다.

학습형 ML을 운영에 추가하지 않는다. 1인량 후보에 대해 전체 관측 날짜의 앞 80%와 뒤 20%를 나눠 메뉴·원재료별 과거 중앙값 기준선을 검증한다. 같은 날짜는 양쪽에 나누지 않고, 학습 구간에서만 중앙값과 표본 자격(5관측·3일 이상)을 계산한다. 같은 날짜·끼니·메뉴·원재료의 다른 1인량은 모호한 이벤트로 제외하고 동일값 반복은 1관측으로 묶는다. 상대 비교는 예측 가능한 동일 검증 집단에서 원재료별 중앙값 기준선을 함께 평가한다. 예측하지 못한 신규·소표본 집단을 커버리지 분모에 포함한다.

검토 보고서는 생성 시각·원본 해시 집합 ID·파서 버전·스냅샷 생성 시각·보고서 버전을 보존한다. 현재 DB와 다르면 보고서를 제공하지 않고 재생성을 안내한다. HTML/JSON 다운로드와 `Run_EDA.command`를 제공하며, 원본 새로고침도 EDA를 함께 생성한다.

브라우저 자동 접근은 앞선 세션에서 보안 승인 거절 상태이므로 다시 시도하지 않았다. API·데이터 분모·시간 분할·다운로드·CSS 팔레트는 프로그램으로 확인했다. 실제 브라우저 렌더링·상호작용·반응형 시각 검증은 미수행이다.
